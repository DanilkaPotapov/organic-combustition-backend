# START HERE

1. Открой Docker Desktop.
2. Выполни `npm install`.
3. Выполни `npm run media:download`.
4. Выполни `npm run db:reset`.
5. Выполни `npm run minio:refresh`.
6. Выполни `npm run start:dev`.
7. Импортируй `postman/Organic_Compounds_Lab3.postman_collection.json`.
8. Выполни запросы по `docs/SCREENSHOT_ORDER.md`.

Если реальные медиа уже скачаны, шаг 3 повторять не нужно.
