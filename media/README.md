# media/

В V3.3 старые сгенерированные картинки и MP4 удалены.

Чтобы заполнить эту папку реальными файлами из Wikimedia Commons, из корня проекта выполни:

```bash
npm run media:download
```

После выполнения здесь появятся:

- methane.png / methane.webm
- ethane.png / ethane.webm
- ethene.png / ethene.webm
- propene.png / propene.webm
- methanol.png / methanol.webm
- ethanol.png / ethanol.webm
- pentane.png / pentane.gif

Источники и лицензии: `docs/MEDIA_SOURCES.md`.
