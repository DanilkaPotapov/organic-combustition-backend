# Сверка ЛР3

- [x] NestJS + TypeScript.
- [x] PostgreSQL + TypeORM.
- [x] MinIO.
- [x] `/api` перед каждым методом.
- [x] Ровно 10 HTTP-методов.
- [x] 7 методов `organic_compounds`.
- [x] 3 метода `users`.
- [x] GET списка только опубликованных услуг.
- [x] Фильтр списка по `carbonCount`.
- [x] GET ленты только опубликованных услуг.
- [x] `?next=true` в том же GET ленты.
- [x] GET draft без ID.
- [x] POST создания принимает реальные файлы image/video.
- [x] Имена файлов генерируются на латинице.
- [x] В БД сохраняются имена файлов, файлы хранятся в MinIO.
- [x] PUT публикации меняет только разрешенные бизнес-поля и статус.
- [x] DELETE — soft delete.
- [x] Удаленные записи не передаются клиенту.
- [x] POST like принимает 0/1.
- [x] Текущий пользователь задан singleton-функцией.
- [x] Регистрация реализована.
- [x] Auth/logout оставлены заглушками для ЛР4.
- [x] Системные поля не принимаются от клиента.
- [x] Предметные поля: carbon_count и hydrogen_count.
- [x] JSON услуги всегда содержит одинаковый набор полей.
- [x] Нет собственных полей statusCode/message в успешном JSON.
- [x] В исходниках нет комментариев.
- [x] README содержит методы и таблицы.
