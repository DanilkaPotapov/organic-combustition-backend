# Проверка ЛР4

Потапов Данил, ИУ5-54Б. Запуск: bash scripts/start.sh. Swagger: http://localhost:3004/api.
Учебные пользователи: potapov@example.local и student2@example.local; пароль Potapov123!.

## Сценарии

1. Аутентификация через POST /api/users/auth в Swagger. Ответ 200 и cookie sessionId.
2. Application → Cookies: sessionId, HttpOnly, SameSite=Lax. Использование cookie браузера в Postman.
3. GET /api/organic_compounds?carbonCount=2 в Swagger: ответ 200 и карточки с признаками isOwner/isLiked.
4. GET списка в Postman без cookie: ответ 200, гостевые признаки равны 0.
5. GET списка с cookie: ответ 200, для собственных карточек isOwner=1.
6. PUT публикации без cookie: ответ 401, тело пустое.
7. PUT публикации с cookie владельца: ответ 200 и заполненные поля.
8. Redis: данные пользователя, TTL сессии и результат npm run redis:users.
9. UML: свойство signature у сообщения publish ссылается на операцию OrganicCompoundsController. Два вызова feed используют одну операцию.
