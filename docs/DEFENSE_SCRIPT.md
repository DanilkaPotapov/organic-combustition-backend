# Сценарий защиты ЛР1

## Короткое вступление

> Моя тема №20 — определение формулы органического соединения по продуктам сгорания. В первой лабораторной я реализовал каталог услуг — формулы простых соединений. Backend на NestJS, серверные шаблоны Handlebars, медиа в MinIO. Дизайн адаптирован с Modern Analytical Sciences и сделан в портретной развертке как Vibes.

## Что показывать по порядку

1. Открой `topics.md`, покажи тему №20.
2. Открой Pixso и покажи 3 экрана: Лента, Добавление, Плитка.
3. Открой те же 3 страницы приложения рядом с макетами.
4. Открой `modernanalytical.com`, затем начало `public/style.css`. Назови 3 цвета и перечисли, что адаптировал.
5. В DevTools → Network покажи три GET: `/compounds/feed/3`, `/compounds/draft`, `/compounds/grid?maxMass=46.07`.
6. Для ленты объясни `id=3` и `?next=true`.
7. Для плитки объясни `maxMass`, серверный `.filter(...)` и сохранение значения в input.
8. В Network → Response плитки найди `data-image-url` / `data-video-url` и покажи MinIO URL.
9. Открой `organic-analysis.data.ts`: одна коллекция, статусы, `likes`, `imageUrl`, `videoUrl`, `formula`, `molarMass`.
10. Открой три `.hbs` и покажи использование URL.
11. Открой controller: ровно три `@Get`, вычисление `likes.length`, отбрасывание `deleted`, поиск `draft`.
12. Открой MinIO Console → `organic-media`.
13. Открой GitHub и ветку `lab1-modern-analytical`.
14. Покажи `uml/lab1-diagrams.drawio` и документацию.

## Фразы на частые вопросы

**Почему на Добавлении ничего не сохраняется?**

> По заданию ЛР1 редактирования нет. Это только интерфейс заполнения черновика. Сохранение появится в следующей лабораторной.

**Почему расчет по CO₂/H₂O пока не работает?**

> В варианте это бизнес-логика заявки, но ЛР1 требует базовую шаблонизацию услуг без БД и изменения данных. Расчет будет добавляться на следующих этапах, а сейчас предметная область отражена формулами и молярными массами услуг.

**Почему Modern Analytical, если сайт не про учебную органику?**

> Это реальный сайт аналитической лаборатории, поэтому его визуальная логика соответствует предметной области: лабораторные услуги, анализ, карточки направлений, строгая научная подача. Я взял только стилистику и адаптировал ее под свою тему и требования Vibes.
