# Источники видео

Актуальный список реальных изображений и видео находится в `MEDIA_SOURCES.md`.

В версии V3.3 нет `externalVideoUrl` и нет сгенерированных fallback-видео. Все опубликованные карточки используют локальный `videoUrl` MinIO, а сам файл предварительно скачивается из открытого интернет-источника командой:

```bash
npm run media:download
```

После этого файлы `.webm`/`.gif` лежат в `media/` и загружаются в bucket `organic-media` командой:

```bash
npm run minio:refresh
```
