# Контрольные вопросы ЛР1 — короткие ответы для письменной части

## 1. Что такое Web?

Web — распределенная информационная система, в которой клиент получает ресурсы от серверов через сеть. Основой являются URL/URI, HTTP/HTTPS и представление документов, обычно HTML.

## 2. Что такое MVC?

MVC — архитектурный шаблон из Model, View и Controller. Model содержит данные и правила предметной области, View отвечает за представление, Controller принимает запрос и выбирает данные/представление.

В моей ЛР1: Model — `OrganicCompound` и `ORGANIC_COMPOUNDS`; Controller — `OrganicAnalysisController`; View — `feed.hbs`, `draft.hbs`, `grid.hbs`.

## 3. Что такое MVT и чем отличается от MVC?

MVT — Model, View, Template. Термин часто используют в Django: View выполняет роль обработчика/контроллера, Template отвечает за HTML. Идея разделения обязанностей похожа на MVC, но названия компонентов отличаются.

## 4. Что такое шаблонизация?

Шаблонизация — формирование HTML по шаблону и данным. В проекте используется Handlebars: Controller возвращает объект, а в `.hbs` значение вставляется, например, через `{{compound.name}}`. Для повторяющихся частей используются partials.

## 5. Что такое HTTP?

HTTP — прикладной протокол обмена сообщениями по модели запрос–ответ. Клиент отправляет метод, URL, заголовки и при необходимости тело; сервер возвращает статус, заголовки и тело ответа.

В ЛР1 используется GET, потому что страницы только читают данные и не изменяют состояние сервера.

## 6. Чем path-параметр отличается от query-параметра?

Path-параметр является частью пути ресурса: `/compounds/feed/3`, где `3` — ID карточки. Query-параметр идет после `?`: `/compounds/grid?maxMass=46.07`; он задает условие фильтрации. `?next=true` тоже query-параметр.

## 7. Модель OSI

OSI состоит из 7 уровней: физический, канальный, сетевой, транспортный, сеансовый, представления, прикладной. HTTP относится к прикладному уровню. TCP работает на транспортном, IP — на сетевом.

## 8. Что такое HTML?

HTML — язык разметки структуры веб-страницы. Теги описывают заголовки, ссылки, формы, изображения, видео и другие элементы. CSS отвечает за визуальное оформление.

## 9. Что делает NestJS Controller?

Controller принимает HTTP-запросы по маршрутам. Декоратор `@Get()` задает GET-маршрут, `@Param()` получает часть URL, `@Query()` — query-параметр, `@Render()` указывает Handlebars-шаблон.

## 10. Для чего нужен MinIO?

MinIO — объектное хранилище. В проекте там лежат PNG/MP4 карточек. В модели хранятся только URL в отдельных полях `imageUrl` и `videoUrl`.

## 11. Почему нет БД и JavaScript?

Это ограничение ЛР1. Все данные услуг берутся из одной коллекции в коде. Фильтрация выполняется на сервере через GET. Клиентский JavaScript не используется.

## 12. Как вычисляется количество лайков?

У услуги есть массив ID пользователей `likes`. Controller вычисляет `likeCount` как `compound.likes.length` и передает число в шаблон.

## 13. Что такое 1НФ и атомарность применительно к ЛР1?

Значение обычного поля должно быть неделимым для выбранной модели. Поэтому `formula` и `molarMass` — отдельные атомарные поля, а не массивы характеристик. Массив `likes` используется отдельно по прямому требованию ЛР1.
