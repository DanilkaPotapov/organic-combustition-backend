# Контрольные вопросы ЛР3 — краткий конспект

## Веб-сервис

Веб-сервис — программный интерфейс, доступный по сети и предназначенный для взаимодействия программ. В ЛР3 клиентом выступает Postman/Insomnia, сервером — NestJS API.

## REST

REST — архитектурный стиль, где ресурс имеет URI, а действие выражается HTTP-методом. GET получает состояние, POST создает или выполняет неидемпотентное действие, PUT изменяет ресурс, DELETE удаляет ресурс логически или физически.

## REST и RPC

REST ориентирован на ресурсы и стандартные HTTP-методы. RPC ориентирован на вызов удаленных функций, поэтому URL чаще описывает действие.

## Основные HTTP-методы

GET — получение данных. POST — создание или действие. PUT — полное/целевое изменение по принятому API. PATCH — частичное изменение. DELETE — удаление. HEAD — заголовки без тела. OPTIONS — доступные возможности/методы.

## Заголовки HTTP

Request headers передают метаданные запроса: `Content-Type`, `Accept`, `Authorization`, `Cookie`. Response headers описывают ответ: `Content-Type`, `Set-Cookie`, cache headers и другие.

## HTTP/1.1, HTTP/2, HTTP/3

HTTP/1.1 работает поверх TCP и поддерживает keep-alive. HTTP/2 также использует TCP, но вводит бинарное кадрирование и мультиплексирование. HTTP/3 работает поверх QUIC/UDP и уменьшает задержки при потерях пакетов.

## HTTPS

HTTPS — HTTP поверх TLS. TLS обеспечивает шифрование, целостность и проверку сервера по сертификату. После TLS-handshake передача HTTP идет в зашифрованном канале.

## OSI
