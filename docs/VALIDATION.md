# Проверка версии V3.3

- в контроллере по-прежнему ровно 3 GET-маршрута;
- `header` и `bottom-nav` явно регистрируются в `src/main.ts`;
- опубликованные карточки используют изображения `.png` и видео `.webm` из MinIO;
- `externalVideoUrl` больше не используется;
- старые сгенерированные медиа удалены из проекта;
- реальные файлы скачиваются командой `npm run media:download`;
- команда `npm run minio:refresh` пересоздаёт локальный учебный bucket и загружает новые файлы;
- список источников и лицензий находится в `docs/MEDIA_SOURCES.md`.
