# Postman

Коллекция содержит ровно 10 сохраненных запросов, то есть по одному на каждый HTTP-метод ЛР3.

Файлы для multipart POST лежат в `postman/files/`. Если Postman после импорта не подхватит относительный путь, выбери эти два файла вручную.

Переменные коллекции:

- `baseUrl = http://localhost:3000/api`
- `draftId` автоматически записывается после POST создания.
- `compoundId` автоматически записывается после PUT публикации.

Для обязательной демонстрации `next=true` используй тот же сохраненный запрос `02 GET feed`: сначала без ID, затем временно поставь `{{baseUrl}}/organic_compounds/feed/{{compoundId}}?next=true`.
