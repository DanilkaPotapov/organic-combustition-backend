# Проверка проекта

ЛР4: сборка NestJS и интеграционный test:e2e с PostgreSQL 17, Redis 7 и MinIO выполнены успешно. Проверены регистрация, bcrypt, cookie, сессии, права двух авторов, загрузка файлов, публикация, лента, лайки, выход и логическое удаление.

Lua: проверены уникальность логинов активных сессий, обработка некорректного JSON и отсутствие истёкших сессий в результате.

ЛР5: сборка TypeScript и Vite выполнена успешно. Проверены mock-коллекция, фильтрация C=2, сброс фильтра, пустая выдача, выбор карточки и циклический переход по ленте.

UML: проверена целостность ссылок MDJ и восемь ссылок signature на операции контроллеров.
