# Результаты проверки ЛР4

Выполнены npm run build и npm run test:isolated. Изолированная проверка использует pg-mem, ioredis-mock и замену загрузки в MinIO. Проверены обе миграции, 11 уникальных Swagger operationId для 10 обработчиков, HTTP-доступ, регистрация, bcrypt, cookie-флаги, сессия, владелец из сессии, запрет чужих изменений, три поля первого шага, короткий ответ {id}, одинаковые ключи карточки с null, фильтрация, лента без id и next=true, повторный лайк, отмена лайка, удаление сессии и soft delete.

Полный Docker-запуск в среде подготовки не выполнялся: Docker здесь отсутствует. Проверка реальных PostgreSQL/Redis/MinIO запускается после миграций командой npm run test:e2e. Реальные скриншоты выполняются на Mac по порядку защиты.

В модели StarUML проверены уникальность идентификаторов, разрешимость всех ссылок, три линии жизни и восемь signature, связанных с операциями контроллеров. Открытие в приложении StarUML не проверялось. Три диаграммы включены в РПЗ и доступны также в Draw.io.
