# Pixso — V3 Compact

Для ЛР1 подготовлены три портретных SVG-фрейма **одинакового размера 430×844**:

- `design/01-feed.svg` — Лента;
- `design/02-draft.svg` — Добавление;
- `design/03-grid.svg` — Плитка;
- `design/pixso-board.svg` — все три экрана рядом.

## Как импортировать

1. Создай новый Design file в Pixso.
2. Импортируй три SVG отдельно.
3. Назови фреймы `01 Лента`, `02 Добавление`, `03 Плитка`.
4. Не растягивай их по высоте: каждый рассчитан на 430×844.

## Что изменено в V3

- все элементы помещаются в один портретный экран;
- плитка содержит **6 компактных карточек** в 2 столбца × 3 строки;
- у каждой карточки есть небольшая картинка, класс, название, формула, молярная масса и короткая строка `CO₂ + H₂O`;
- убраны длинный hero-блок, большая статистика и растянутые карточки;
- экран добавления тоже полностью помещается в 430×844;
- палитра сохранена из Modern Analytical Sciences: `#00B4D8`, `#0090AE`, `#0F1A24`, `#E8F6FA`, `#F0F4F8`.
