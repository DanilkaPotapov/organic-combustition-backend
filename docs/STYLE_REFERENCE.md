# Привязка дизайна к Modern Analytical Sciences

Прототип: https://modernanalytical.com/

В версии V2 цвета и приёмы взяты не «на глаз», а из исходного HTML страницы, который был предоставлен для работы.

## Палитра

- `#00B4D8` — основной cyan (логотип, акценты, линии, кнопки);
- `#0090AE` — более тёмный cyan;
- `#0F1A24` — основной тёмный текст;
- `#52677A` — серо-синий вторичный цвет;
- `#6B8294` — muted-текст;
- `#5A7080` — подписи и метаданные;
- `#E8F6FA` → `#F0F4F8` — градиент hero-блока;
- `#FFFFFF` — карточки и навигация.

## Типографика

В исходной странице подключены:

- `Inter` — основной UI;
- `Newsreader` — выразительные заголовки;
- `DM Mono` — индексы, технические подписи и небольшие метки.

В проекте сохранена эта логика с системными fallback-шрифтами.

## Приёмы интерфейса

Из прототипа адаптированы:

1. белая верхняя навигация;
2. светло-голубой hero с научной сеткой;
3. cyan-кнопки и тонкие cyan-линии;
4. статистическая линейка с точками;
5. карточки с изображением, названием, тегами и стрелкой;
6. нумерация элементов (`01`, `02` и т. д.);
7. форма в стиле sample intake / submit samples;
8. светлая лабораторная подача и много свободного пространства.

По требованиям ЛР1 композиция дополнительно адаптирована под портретный формат и Vibes-ленту с нижней навигацией.
