# V3.3 — Real Media

Основное изменение этой версии: карточки больше не используют сгенерированные для проекта картинки и ролики.

Для 6 опубликованных соединений подобраны реальные открытые материалы из Wikimedia Commons / NASA / ESO:

- Метан — 3D-модель + NASA-визуализация химии метана;
- Этан — 3D-модель + NASA-анимация образования этана;
- Этен — 3D-модель + анимация полимеризации этена;
- Пропен — 3D-модель + NASA-видео о пропилене на Титане;
- Метанол — 3D-модель + ESO-визуализация области, где обнаружен метанол;
- Этанол — 3D-модель + лабораторное видео горения этанола.

Скачивание:

```bash
npm run media:download
```

Обновление MinIO:

```bash
npm run minio:refresh
```

Подробности: `docs/MEDIA_SOURCES.md` и `docs/REAL_MEDIA_RESTART.md`.
