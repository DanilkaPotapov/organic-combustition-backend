# Источники демонстрационных медиа

Скрипт `scripts/download-organic-compounds-media.sh` скачивает открытые материалы из Wikimedia Commons.

- Methane 3D model — Wikimedia Commons, `Methane-3D-vdW.png`
- Ethane 3D model — Wikimedia Commons, `Ethane-3D-vdW.png`
- Ethene 3D model — Wikimedia Commons, `Ethylene-CRC-MW-3D-vdW.png`
- Propene 3D model — Wikimedia Commons, `Propylene-GED-MW-3D-bs-17.png`
- Methanol 3D model — Wikimedia Commons, `Methanol-3D-vdW.png`
- Ethanol 3D model — Wikimedia Commons, `Ethanol-3D-vdW.png`
- Methane/Titan animation — Wikimedia Commons / NASA visualization
- Ethane/Titan animation — Wikimedia Commons / NASA visualization
- Ethene polymerization animation — Wikimedia Commons
- Propylene on Titan animation — Wikimedia Commons / NASA
- Methanol/TW Hydrae animation — Wikimedia Commons / ESO visualization
- Ethanol combustion video — Wikimedia Commons

Точные URL находятся в самом скрипте загрузки. Перед публичной публикацией проекта проверь лицензию каждого конкретного файла на его странице Wikimedia Commons.
