# Git для ЛР3

Рекомендуемая отдельная ветка:

```bash
git checkout -b lab3-organic_compounds-rest-api
git add .
git commit -m "lab3: organic_compounds rest api"
git push -u origin lab3-organic_compounds-rest-api
```

Перед защитой:

```bash
git status
git branch
git log --oneline --decorate -5
```
