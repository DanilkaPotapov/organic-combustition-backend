# Диаграммы ЛР4

Potapov_LR4.drawio — три редактируемые страницы: ER, классы, последовательность.
Potapov_LR4.mdj — единый проект StarUML с тремя диаграммами. У восьми сообщений последовательности поле signature ссылается на операции контроллеров диаграммы классов. Выберите сообщение → Properties → signature.
Содержимое и ссылки MDJ проверены программно; открытие в установленном StarUML нужно проверить на своём Mac.

SVG/PNG — изображения этих диаграмм для РПЗ. В ER отсутствует сетка; необязательные поля отмечены только NULLABLE. У классов страниц три секции и две разделительные линии. Классы страниц задают целевой SPA следующих лабораторных.

Оформление JSON моделей опирается на официальный формат примеров https://github.com/staruml/staruml-samples (MIT). См. THIRD_PARTY_NOTICES.txt.
