# Диаграммы ЛР4

Potapov_LR4.drawio: три редактируемые страницы ER, UML классы, последовательность. Все заголовки с белой заливкой. В ER модификаторы в отдельном третьем столбце. Поля страниц и моделей на диаграмме классов не детализированы; HTTP контракты выделены стереотипом interface.

Potapov_LR4.mdj: проект StarUML. У восьми вызовов signature ссылается на реальные UMLOperation контроллеров; две операции feed используют одну signature.

В РПЗ SVG имеет ширину 250 мм. Кегль сообщений 18 × 250 / 1000 × 72 / 25.4 = 12.76 пт (4.5 мм). Чёрточка на sequence имеет длину 10 мм при печати без масштабирования. Высота печатной буквы меньше кегля и проверяется по фактическому отпечатку.
